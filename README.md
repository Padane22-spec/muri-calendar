# 木日 · 四季木作日历拼图

在 43 格日历底盘上摆放 8 块固定积木，仅露出所选月份和日期。全部 366 个有效月日组合均经过求解验证，包括 2 月 29 日。

React + TypeScript + Three.js + Vite；支持桌面鼠标与手机触屏操作，无后端。

## 启动与停止

需要 Node.js 22.18+。

~~~sh
npm install
npm run dev
~~~

访问终端显示的本地地址，通常是 http://localhost:5173 。停止服务时，在该终端按 Control + C。

~~~sh
npm run build         # 类型检查及生产打包
npm run preview       # 预览生产版本
npm test              # 规则、会话、存档和印章测试
npm run verify:dates  # 全部 366 个日期的可解性验证
~~~

## 部署到 GitHub Pages

1. 在 GitHub 创建公开的空仓库，将本地代码推送到 `master` 分支。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 首次上传若早于 Pages 设置，在 **Actions → Deploy to GitHub Pages → Run workflow** 中手动运行一次。
4. 工作流通过测试、366 个日期验证和生产构建后自动发布；网站链接显示在 **Settings → Pages** 及部署任务中。

之后每次推送到 `master` 都会自动更新网站。若更改默认分支，请同步修改 `.github/workflows/deploy.yml` 的触发分支。Vite 使用相对资源路径，兼容 `https://用户名.github.io/仓库名/` 和自定义域名。

部署无需服务器或环境密钥。每位玩家的存档独立保存在自己的浏览器中。

## 四季木作

- 深色胡桃木边框、凹槽与浅木内盘，配黄铜铭牌。
- 整体挤出的倒角积木、连续程序木纹和细微凹凸；木纹随积木旋转、翻转。
- 春芽绿、夏青绿、秋赭金、冬灰蓝：按挑战月份改变植物刻纹、目标日期、界面和印章。
- 悬停显示积木名称；抬起、吸附、旋转和翻面带短动画。
- 轻微木块音效在用户操作后启用，可静音；静音设置保存在当前浏览器。页面失焦时不播放。
- 系统开启“减少动态效果”时简化场景及庆祝动画。

## 操作与历史

- 按住左键拖动；滚轮每步旋转 90°；右键翻转。
- R / Shift+R 旋转，F 翻转，Esc 取消拖动。
- 触屏：单指拖动，松手落子；轻点只选中，不改变局面。选中后用下方“左转 / 右转 / 翻面”按钮调整，也可按住积木时用另一指操作按钮。
- 窄屏底盘下方显示两排积木托盘；拖出后恢复实际大小。未落入底盘的积木返回托盘，取消触摸或屏幕尺寸变化恢复拖动前的状态。
- 绿色预览可以放下；红色表示重叠、越界或遮住目标日期。非法落子和取消恢复原状态，不进入历史。
- Ctrl / Cmd + Z 撤销；Ctrl / Cmd + Shift + Z 重做，也可点击按钮。
- 一次拖动中的旋转、翻面合为一步；单独旋转、翻面及一次提示分别为一步。历史最多保存 100 步，新操作清空重做分支。
- 日期选择可切换任意日期。按完整年月日自动保存局面、桌面积木位置、朝向和历史；刷新后从今天的存档恢复，切回其他日期加载该日局面。

## 印章日历

展开“我的木作日历”即可切换月份、点击日期挑战、返回今天、查看本月已完成数量。

- **实心印章**：本次尝试独立拼好。
- **线框印章**：本次尝试使用过成功提示后拼好。
- **参考留痕**：查看完整答案，仅记录看过答案，不计入已完成数量。
- 撤销不会清除本次尝试的提示和答案记录。
- “重新挑战”清空当前局面、历史及本次辅助标记，保留历史印章。
- 同一天历史成绩只升级，不降级；不同年份分别记录。
- 通关显示纪念卡；恢复已完成的存档不会重复播放庆祝。

“给我一点灵感”会保留已有落子并放好下一块。布局确实无解与搜索达到上限会显示不同提示；未放下提示积木时不会标记辅助使用。

## 保存和兼容性

数据保存在 localStorage 的 muri-calendar-v1 项中，仅限当前浏览器和站点，不跨设备同步。使用带版本号的格式，恢复时校验日期、积木形状、位置和重叠；损坏局面回退为新局。存储被禁用或空间不足时游戏仍可继续，并显示不能保存的提示。

需要 WebGL 与浏览器硬件加速。所有木纹、植物符号与音效在本地生成，无远程图片、字体、音频或模型依赖。首次进入按浏览器本地日期选择今日挑战。

## 代码结构

- src/game/puzzle.ts：拼图规则及带状态的回溯求解。
- src/game/session.ts：独立会话、撤销重做、存档校验和印章升级。
- src/game/Scene.ts：3D 渲染、动画、拾取及临时拖动状态。
- src/game/theme.ts、wood.ts、audio.ts：季节、程序材质与音效。
- src/App.tsx：页面、会话编排、印章日历及持久化。

场景通过快照同步与提交回调连接会话，拖动中的临时状态不会覆盖已保存的局面。
