# 木日 · 日历拼图

桌面浏览器中的木质日历拼图，使用 React、TypeScript、Three.js 和 Vite。8 块固定形状的木块共覆盖 41 格；在 43 格底盘上只露出目标月份和日期即成功。全部 366 个有效月日组合经过求解验证，包括 2 月 29 日。

## 本地运行

需要 Node.js 22.18+。

```sh
npm install
npm run dev
```

打开终端提示的本地地址，通常是 http://localhost:5173 。

```sh
npm run build        # TypeScript 检查和生产打包
npm run preview      # 预览生产构建
npm test             # 形状变换、放置规则、胜利判定、提示求解
npm run verify:dates # 全部 366 个有效月日组合验证
```

## 操作

- 悬停轻微抬起；按住左键拖动，松开自动吸附网格。
- 滚轮每次旋转 90°，右键翻转；也支持 R / Shift+R 旋转、F 翻转。
- Esc 取消拖动，恢复之前的位置与朝向。
- 绿色预览表示可放；红色表示重叠、越界或遮住目标日期。非法落子恢复原位。
- 日期按钮切换挑战并重置积木。
- “给我一点灵感”在保留当前摆放的前提下放好下一块；当前布局无解时提示调整。
- “看看参考拼法”展示完整答案；重置后可重新挑战。

第一版面向桌面鼠标操作，需要浏览器支持 WebGL 和硬件加速。刷新会重新开始，不保存局面。

## 实现

- `src/game/puzzle.ts`：底盘、积木、旋转镜像、放置判定和回溯求解器。
- `src/game/Scene.ts`：正交相机、木纹贴图、完整积木轮廓挤出、阴影、拾取、拖放与预览。
- `src/App.tsx`：日期选择、进度、提示和胜利界面。

木纹在浏览器中生成，无需远程图片、字体服务或后端。每日日期按浏览器本地日历初始化。
